# Ayllu (Flying of the Condor)

## Project Overview

Ayllu is a story-driven Mixed Reality (MR/VR) experience featuring redirected-walking gameplay, portal transitions, and interactive events.

I was responsible for **rebuilding and optimizing the project independently within a two-week timeframe** after the previous team was unable to deliver a working version. My task was to recreate the required functionality, resolve technical issues, optimize the portal systems, and ensure the experience was stable and ready for demonstration.

## My Contributions

- **Independent Development:** Rebuilt the required version of the project largely from scratch within two weeks.
- **Portal Systems:** Reimplemented, debugged, and optimized the portal systems, ensuring the portals functioned correctly and transitions worked as intended.
- **System Implementation:** Recreated redirected-walking gameplay and the required event flow.
- **Optimization:** Improved the portal implementation and addressed technical issues to make the experience more reliable.
- **Testing and Debugging:** Identified and resolved issues to ensure the main gameplay systems worked as intended.
- **Client Delivery:** Prepared a functional version of the experience and presented it to the XR Lab client within the deadline.

## Technologies

- Unity
- C#
- Mixed Reality / Virtual Reality (MR/VR)
